# Pixel Studio - Advanced Pixel Art Editor

A sophisticated, web-based pixel art editor built with Vanilla JavaScript, HTML5, and CSS3. Features a modern glassmorphic UI, responsive design, and advanced editing tools.

## 🌐 Live Demo - taseen2.github.io/Pixel-Art/ 


[![Pixel-Studio-Advanced-Editor.png](https://i.postimg.cc/QCbmxLPx/Pixel-Studio-Advanced-Editor.png)](https://postimg.cc/MfnVdLqh)
## 🎨 Features

-   **Dynamic Grid Sizes**: Choose from 8x8, 16x16, 32x32, or 64x64 canvas sizes.
-   **Advanced Drawing Tools**:
    -   **Brush**: Smooth drawing with customizable brush sizes (1px to 5px).
    -   **Eraser**: Easily remove colors from individual pixels.
    -   **Rectangle Fill**: Hold `Shift` + Click to fill the rectangular area between two points.
-   **Color Management**:
    -   Quick-access color palette.
    -   Full hex color picker for custom colors.
-   **History Management**: Full Undo (`Ctrl+Z`) and Redo (`Ctrl+Y`) support (up to 50 steps).
-   **View Controls**: Zoom in/out to handle fine details or see the big picture.
-   **Export functionality**: Save your creations as high-quality PNG files.
-   **Dark/Light Mode**: Fully themed interface with a seamless toggle.
-   **Responsive UI**: Modern glassmorphic sidebar and polished interactive elements.

## 🚀 Getting Started

To run the Pixel Studio editor locally:

1.  Clone this repository:
    ```bash
    git clone https://github.com/yourusername/pixel-art-editor.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd pixel-art-editor
    ```
3.  Open `pixel-art.html` in your favorite web browser.

## 🛠️ Built With

-   **HTML5**: Semantic structure and Canvas for exports.
-   **CSS3**: Custom properties (variables), Glassmorphism, Flexbox, and CSS Grid.
-   **Vanilla JavaScript**: State management, DOM manipulation, and history tracking.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl` + `Z` | Undo |
| `Ctrl` + `Y` | Redo |
| `Shift` + `Click` | Rectangle Fill |
