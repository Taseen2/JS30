# Premium Product Search UI ✨

A modern and responsive product search interface built using **HTML, CSS, and JavaScript**.  
Users can search products in real-time with a clean premium-style UI.

---

## 🚀 Features

- 🔍 Real-time product search
- ⚡ Dynamic filtering using JavaScript
- 🎨 Premium dark UI design
- 🏷️ Discount badge system
- 💰 Automatic discounted price calculation
- 📦 Products loaded from JSON
- 📱 Responsive product grid
- ✨ Smooth animations and hover effects

## ⚙️ How It Works

1. Products are stored inside `products.json`
2. JavaScript fetches the data using Fetch API
3. Products are dynamically rendered on the page
4. Search input filters products instantly
