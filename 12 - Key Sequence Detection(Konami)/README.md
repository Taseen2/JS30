# 🚀 Meme Mode: The Ultimate Konami Code Easter Egg

A high-performance, visually stunning "Meme Mode" Easter egg built with Vanilla JavaScript, CSS3, and the Web Audio API. Triggered by the legendary Konami Code, this project transforms a minimal landing page into a chaotic, neon-drenched celebration of internet culture.

## ✨ Features
- **🎮 Konami Code Detection:** Robust sequence tracking for `↑ ↑ ↓ ↓ ← → ← → B A`.
- **🎭 Dynamic Meme Engine:** Spawns random, culturally diverse memes (including Indian legends like the "Disappointed Cricket Fan").
- **🔊 Procedural Audio:** Funny cartoon sound effects synthesized in real-time via **Web Audio API** (no external MP3s needed!).
- **✨ Visual FX:** 
  - Glassmorphism & Neon UI aesthetics.
  - Interactive **Cursor Trail** effect.
  - CSS3 **Screen Shake** and **Background Glow** transitions.
  - Confetti bursts on activation via `canvas-confetti`.
- **🏆 Achievement System:** Persistent "Meme Lord" status saved via `localStorage`.
- **📱 Fully Responsive:** Lightweight and optimized for both desktop and mobile.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure and overlay management.
- **CSS3:** Advanced keyframe animations, backdrop-filters, and custom properties.
- **JavaScript:** ES6+ logic, event listeners, and procedural audio synthesis.

## 🚀 Quick Start
1. Clone the repo.
2. Open `index.html` in any modern browser.
3. Enter: `↑ ↑ ↓ ↓ ← → ← → B A`
4. **Enjoy the chaos!**
